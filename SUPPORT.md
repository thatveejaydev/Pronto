# PRONTO Support

## Before reporting a problem

1. Confirm you are using Windows 10/11 and Premiere Pro 24.0 or newer.
2. Close Premiere, reinstall PRONTO, and reopen the project.
3. Reproduce the issue in a duplicate project or after saving a backup.
4. Run `npm test` and `npm run validate:hotkey` from the repository root.

## What to include

- PRONTO version and Premiere Pro version.
- Windows version.
- Media type, audio channel layout, and destination track configuration.
- Exact reproduction steps and the error shown by PRONTO.
- Whether the issue occurs in a new minimal project.

Do not attach confidential projects or media. Report reproducible problems through the [GitHub issue tracker](https://github.com/thatveejaydev/Pronto/issues).

## Safety

Save the project before testing placement behavior. If Premiere places an item unexpectedly and PRONTO requests it, use **Undo** immediately.
